## 去重说明
- 与图片版完全重复或仅拼写变体的 15 条不再重复收录（如 No pains, no gains / Well begun is half done / Rome was not built in a day 等）。
- 中文释义相同、保留其一的近义组 5 条：More hasty less speed（留 Haste makes waste）、Do as the Romans do（留 When in Rome...）、One false step will make a great difference（留 A miss is as good as a mile）、Well begun（两条均留 A good beginning is half done）。
- 释义微调：Better late than never 释义收窄为「迟做总比不做好」，避免与 It's never too late to mend（亡羊补牢，为时未晚）在选择题中产生双正确项。
